## Контекст для Claude Code

В корне проекта лежит папка `design_handoff_realmweaver_ui/` — дизайн-референс редизайна
интерфейса. Главный документ — `design_handoff_realmweaver_ui/README.md`: там точные
цветовые токены (2 темы), типографика, размеры, разбор всех 6 экранов и модель состояния.
Скриншоты — в `design_handoff_realmweaver_ui/screens/dark/` и `.../light/`.

**Важно:**
- Файлы `*.dc.html` и `support.js` в пакете — это **браузерный референс, а не код на копирование**.
  Реализуй дизайн в нашем существующем окружении: **runtime C# поверх `UnityEngine.UI`**
  (старый uGUI), никаких префабов, UI Toolkit/UXML. Шрифт — `LegacyRuntime.ttf`.
- Полигональная карта на макетах — плейсхолдер: её рисует наш существующий генератор.
  Из макетов реализуем **панели и хром**, а не отрисовку карты.
- Не переписывай архитектуру целиком. Встраивайся в текущий код, где UI уже строится кодом.

Перед началом прочитай `design_handoff_realmweaver_ui/README.md` целиком и оглядись в текущем
коде UI (где создаются панели «Слои», легенда, тулбар заметок, панель POI, диалоги).

## Порядок работы (по одному шагу, с проверкой после каждого)

### Шаг 1 — Система токенов и темы
- Заведи `enum Role` и два словаря `Dictionary<Role,Color>` (Dark/Light) — **готовый код есть
  в README, раздел «Design Tokens (сводка для C#)»**.
- Реализуй `ApplyTheme(Theme t)`: каждый создаваемый `Image`/`Text` регистрируется со своей
  `Role`, метод проходит по списку и присваивает `graphic.color`.
- Добавь настройку `Theme theme` (Dark/Light) с сохранением в конфиг и переключатель в меню.
- **Проверка:** переключение темы мгновенно перекрашивает уже существующий UI.

### Шаг 2 — Экран генерации (пустое состояние)
- Референс: README раздел **B**, скриншот `screens/*/02-generate.png`.
- Введи состояние `bool mapGenerated`. Пока карта не создана — прячь редактор карты и легенду,
  показывай карточку генерации (сид + «Случайно», размер, форма суши, детализация, кнопки
  «Сгенерировать» / «Открыть проект…»).
- **Проверка:** запуск без проекта показывает экран генерации, а не пустой редактор.

### Шаг 3 — Прогресс генерации
- Референс: README раздел **E**, скриншот `screens/*/03-progress.png`.
- Между экраном генерации и рабочим — карточка с прогресс-полосой, чек-листом шагов и «Отмена».
- **Проверка:** во время генерации виден прогресс; по завершении — рабочий экран.

### Шаг 4 — Главный экран: панели «Слои» и «Легенда»
- Референс: README раздел **A**, скриншот `screens/*/01-main.png`.
- Приведи «Слои» и легенду к карточкам с заголовками, пристыкованным к краям карты; строки
  «чекбокс + подпись» вплотную; активная строка — подложка `--accent-soft`.
- **Проверка:** панели больше не «висят в пустоте», отступы ровные.

### Шаг 5 — Тулбар и сайдбар заметок
- Референс: README раздел **A** (регион заметок).
- Сгруппируй иконки тулбара в контейнер, добавь поле поиска; сайдбар страниц — дерево
  групп/страниц с активным состоянием.
- **Проверка:** иконки в едином контейнере, тулбар консистентен с тулбаром карты.

### Шаг 6 — Редактор: панель кисти
- Референс: README раздел **C**, скриншот `screens/*/04-editor-brush.png`.
- Панель кисти (цель, режим, форма, размер, сила) + контекстная палитра биома.
- **Проверка:** все контролы кисти собраны в одну панель по токенам.

### Шаг 7 — Точки интереса
- Референс: README раздел **D**, скриншот `screens/*/05-poi.png`.
- Список POI (поиск, фильтры по типам) + панель редактирования (имя, тип, описание, иконка,
  привязка заметок, удаление/готово).
- **Проверка:** выбор точки открывает панель редактирования по спеке.

### Шаг 8 — Модальные диалоги
- Референс: README раздел **F**, скриншот `screens/*/06-modals.png`.
- Приведи подтверждения/ошибки к единому виду: затемнённая подложка + центральная панель.
  Правило кнопок: primary = `--accent`; деструктив = `#C9605A`; отмена = secondary `--elev`.
- **Проверка:** удаление POI и ошибка сохранения используют общий стиль диалога.

## Общие правила
- Все цвета — только из токенов по `Role`; не хардкодь hex вне таблицы тем (кроме семантики
  карты/биомов и danger `#C9605A` — они в README).
- Маппинг «HTML → uGUI» описан в README (раздел «About the Design Files»): `div` → `Image`,
  `flex/gap` → `Horizontal/VerticalLayoutGroup`, `grid` → `GridLayoutGroup` и т.д.
- Тени и скругления не критичны — при сложности реализации допустимы прямые углы/без теней.
- После каждого шага — короткая проверка в редакторе/сборке, потом следующий шаг.
