# Handoff: RealmWeaver — редизайн UI (тема + панели)

## Overview / Обзор
Редизайн интерфейса **RealmWeaver** — десктопного Unity-приложения (генератор фэнтезийных
карт мира + Notion-подобный слой заметок). Пакет покрывает:

- **A. Главный экран** — карта слева (вкладки Карта / Редактор / Точки, панель «Слои»,
  легенда) + слой заметок справа (тулбар, сайдбар страниц, canvas с карточками).
- **B. Экран генерации** — состояние «карта не создана»: панель с параметрами
  (сид, размер, форма суши, детализация) и кнопкой «Сгенерировать карту».
- **C. Редактор — кисти** — панель кисти (цель правки, режим, форма, размер, сила)
  и контекстная палитра биома.
- **D. Точки интереса** — список POI с фильтрами + панель редактирования точки.
- **E. Генерация идёт** — прогресс-состояние (полоса %, чек-лист шагов, «Отмена»).
- **F. Модальные диалоги** — подтверждение (danger) и ошибка над затемнённой подложкой.

Плюс **единая система токенов** и **переключатель Тёмная/Светлая тема** (одна кнопка
перекрашивает все экраны).

---

## About the Design Files / О файлах
Файлы в этом бандле — **дизайн-референсы, свёрстанные в HTML**. Это прототипы,
показывающие _намеренный внешний вид и поведение_, а **не production-код для копирования**.

Задача: **воссоздать эти макеты в существующем окружении проекта RealmWeaver** —
рантайм-код на **C# поверх `UnityEngine.UI`** (старый uGUI): `new GameObject()`,
`AddComponent<Image>()`, `AddComponent<Text>()`, `AddComponent<Button>()`,
`HorizontalLayoutGroup` / `VerticalLayoutGroup` / `GridLayoutGroup`, `LayoutElement`.
Никаких префабов, UI Toolkit/UXML — только код. Шрифт — встроенный `LegacyRuntime.ttf`.

HTML-структура намеренно проста и **1:1 ложится на uGUI**:
- каждый `<div>` со `background` → `Image` (или Panel);
- `border` → второй `Image`-обводка / `Outline`, или родитель-«рамка» на 1px больше;
- `border-radius` → sliced-спрайт со скруглением (одна общая спрайт-«таблетка» на радиус);
- `display:flex; gap` → `Horizontal/VerticalLayoutGroup` со `spacing = gap`;
- `display:grid` → `GridLayoutGroup`;
- текст → `Text` (или TMP, если проект уже на TextMeshPro).

> Тени (`box-shadow`) в uGUI дороги — можно опустить или заменить лёгким полупрозрачным
> спрайтом/`Shadow`-компонентом. Скругления не критичны: при желании допустимы
> прямые углы, макет от этого не ломается.

## Fidelity
**High-fidelity (hi-fi).** Финальные цвета, размеры, отступы и типографика заданы точно
(см. Design Tokens). Воссоздавать по значениям из этого README. Полигональная карта на
макетах — плейсхолдер (реальную карту рисует существующий генератор); важны **панели и хром**.

## Interactions & Behavior
- **Переключение вкладок** (Карта/Редактор/Точки): меняет содержимое левой панели поверх
  того же вьюпорта карты. Активная вкладка — `--accent`.
- **Переключатель темы:** одна настройка `Theme { Dark, Light }`; смена вызывает
  `ApplyTheme()` — переприсваивает цвета всем элементам по их роли (мгновенно, без перезагрузки).
- **Разделитель** карта/заметки — перетаскивание по X (drag), меняет ширины двух регионов.
- **Панель «Слои»:** тумблеры показывают/скрывают слои рендера карты.
- **Кисть:** ЛКМ-рисование по карте по выбранной цели/режиму; размер и сила — слайдеры;
  «Биом» открывает палитру; Undo/Redo в тулбаре.
- **POI:** клик по карте создаёт точку; выбор в списке/на карте открывает панель
  редактирования; «Удалить» — через модальное подтверждение (см. ниже); перетаскивание
  маркеров по карте.
- **Экран генерации → рабочий:** «Сгенерировать карту» скрывает пустое состояние и показывает
  карту + панели. (Рекомендуется отдельное состояние «генерация идёт» с прогрессом — в макетах
  пока нет, стоит добавить.)
- **Наведение (hover):** строки/кнопки на `--elev`/`--accent-soft`; для uGUI —
  `Button.colors` или `ColorBlock` на роль.
- **Модальные диалоги** (существующий паттерн): тёмная полупрозрачная подложка + центральная
  панель на `--panel` с бордером; кнопки — primary `--accent`, danger `#C9605A`.

## State Management
Минимальный набор состояний UI:
- `Theme theme` (Dark/Light) — глобально, persist в настройках.
- `MapTab activeTab` (Map/Editor/Points).
- `bool mapGenerated` — переключает экран B ↔ рабочий экран.
- Параметры генерации: `seed (string)`, `size (S/M/L)`, `landShape (enum)`, `detail (int)`.
- `Brush { target(Height/Temp/Humidity/Biome), mode(Raise/Lower/Smooth), shape(Circle/Square),
  size(int), strength(0..100), selectedBiome }`.
- `List<Poi>` + `Poi selectedPoi` (имя, тип, описание, iconId, linkedNotesGroupId).
- Notes: группы/страницы, выбранная страница, объекты canvas (карточки/изображения/связи).
- `float splitRatio` — позиция разделителя.

## Assets / Иконки
Все иконки в макетах **нарисованы из примитивов** (прямоугольники, круги, линии, галочки) —
можно реализовать как sliced-спрайты или как простые `Image`/`Text`-глифы, чтобы не тянуть
внешние ресурсы:
- Тулбар заметок: стрелка-выбор, рамка (карточка), рамка+кружок (изображение),
  2 узла + линия (связь), карандаш (рисование), лупа (поиск).
- Слои: чекбокс (квадрат + галочка).
- Генерация: ↻ (случайно), ✦ (генерация), папка (открыть).
- POI-типы: дом, колонны, арка, зубчатая стена (см. выше).
Пользовательские иконки POI загружает сам пользователь (кастомная иконка точки) —
плитка «+» в панели редактирования.

## Files / Файлы в бандле
- `PROMPT.md` — **пошаговый план для Claude Code** (с чего начать и в каком порядке).
- `RealmWeaver Redesign.dc.html` — **обзорный лист**: аудит, переключатель темы, все 4 экрана
  под активной темой. Открой в браузере, чтобы кликнуть по тумблеру Тёмная/Светлая.
- `MapScreen.dc.html` — экран A (главный).
- `GenScreen.dc.html` — экран B (генерация / пустое состояние).
- `EditorScreen.dc.html` — экран C (кисти).
- `PoiScreen.dc.html` — экран D (точки интереса).
- `ProgressScreen.dc.html` — экран E (генерация идёт).
- `Modals.dc.html` — экран F (модальные диалоги).
