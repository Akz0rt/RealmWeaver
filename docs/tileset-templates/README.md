# Трафареты и схемы для тайлов города

Всё построено скриптом по числам из `SettlementVolumeRenderer.cs` и `SettlementTileGrid.cs`
(`tiltSquash 0.8`, `tileOverdraw 1.04`, `eastFaceFraction 0.22`, `ShadowScale 1.15`,
`ShadowOffsetCells 0.14`, `frontShade 0.72`, `eastShade 0.52`, высоты `0.55 / 0.85 / 1.10 / 1.25`),
а не нарисовано на глаз. Правила и развилки — в `docs/tileset-authoring.md`.

## Трафареты — их кладут ОТДЕЛЬНЫМ ВЕРХНИМ СЛОЕМ поверх холста

Все три — 128×128, прозрачные, розовые направляющие. В файл, который пойдёт в игру, они попасть не должны:
открой трафарет, положи поверх своего слоя, рисуй под ним, перед экспортом выключи.

| Файл | Для каких слотов | Что показывает |
|---|---|---|
| `stencil-flat-128.png` | `roadGround`, `voidGround` | рамка = граница клетки. Рисуй до самого края: рендер сам ужимает тайл на 1 px, и в этот зазор видна линия сетки |
| `stencil-volume-top-128.png` | `buildingGround`, `wallGround`, `gateGround` | внешняя розовая полоса ≈2 px — тайл рисуется на 4% крупнее клетки и этой полосой заезжает на соседа. Жёсткой рамки по краю быть не должно: на стыке она удвоится |
| `stencil-wallface-128.png` | `wallSprite` | горизонтальные полосы и стрелки: фактура должна стыковаться левым краем с правым и переживать любое растяжение по высоте |

## Схемы — их не рисуют, на них смотрят

| Файл | О чём |
|---|---|
| `sheet-tile-geometry.png` | как квадрат 128×128 становится клеткой 5:4; из чего состоит объёмный тайл (верх, передняя грань, восточная полоска 0.22, тень); высоты дома/ворот/стены |
| `sheet-wallsprite-stretch.png` | один и тот же тайл, растянутый во все шесть реальных размеров `wallSprite` (от 1.89:1 до 0.18:1). Сверху — почему фасад с окнами плывёт, снизу — почему бесшовная фактура держится |
| `sheet-town-fragment.png` | фрагмент города, собранный по формулам рендера в реальном порядке отрисовки: один дом на две клетки против двух домов вплотную, стена, ворота, улица, двор, тень |

Генератор лежит рядом — `_generate.py` (Python + Pillow). Если в рендере поменяются числа, схемы пересобираются
одной командой, а не перерисовываются руками.
